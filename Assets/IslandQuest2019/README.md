# 潮岸遗物：Unity 2019 原创数字资产与第三人称试炼

目标：Unity **2019.3.0f6** + URP 7.2.1，在已有去船海岛工程中运行。

原创网格：海岛剑士（1882 三角形）、骷髅守卫（3115）、升级宝箱（1508）、三阶长剑（278 / 286 / 290）。模型由随包 Blender 建模脚本生成，具有独立材质、可转动肢体、宝箱盖铰链和武器插槽；不使用外部付费模型、Avatar 或动画包。模型 JSON 保存真实顶点与三角形，编辑器工具将其保存为可重复使用的 `.asset` 网格、`.mat` 材质与 `.prefab` 预制体。

## 生成与使用

1. 安装文件后等待 Unity 编译；菜单 **Island2019 → 1 - Build Assets and Gallery** 生成资产及展示场景。
2. 展示场景点击 Play，0 总览、1 主角、2 骷髅、3 武器、4 宝箱；鼠标拖动旋转，滚轮缩放。F1 隐藏文字，F8 拍摄双倍分辨率截图，保存到工程根目录 `Screenshots`。截图分辨率取决于 Game 窗口大小，建议先选 1920×1080、将 Game 窗口最大化。
3. **Island2019 → 2 - Build Island Combat Scene** 从 `island_clean_2019.unity` 另存新场景，在海岛干燥地形上放置战斗石台；原静态场景文件保留。此版战斗围绕石台，尚不是整个海岛的任务关卡。
4. 点击 Play：WASD 行走，Shift 奔跑，空格跳跃，鼠标转镜头，滚轮调镜头距离，左键挥剑，靠近宝箱按 E。Esc 释放鼠标，点击画面继续。角色死亡后按 R 重试。

## 数值

- 主角生命 100，行走 4.5、奔跑 7 米/秒；近战冷却 0.65 秒。
- 六只骷髅生命依次 54、54、76、76、100、100；攻击伤害 12、间隔 1.4 秒；玩家受击保护 0.75 秒。
- 击败 2 只后可开第一只宝箱，击败 4 只后可开第二只；武器伤害 18 → 30 → 48。开箱额外恢复 30 生命，上限 100。
- 宝箱每只仅能开一次；清除六只骷髅完成试炼。

## 保存的资产

生成目录 `Assets/IslandQuest2019/Generated`：Meshes、Materials、Prefabs。生成的场景：`Assets/scenes/quest_assets_2019.unity`、`quest_adventure_2019.unity`。重复生成更新这些派生文件；请先备份自己的场景编辑。

随包总览 PNG 为真实 Blender 模型渲染，不代表 Unity 内截图。作业可在展示场景自己取景截图，建议总览一张、角色及骷髅一张、武器与宝箱一张。作业通知的提交内容为成品截图，截止 2026-10-18 23:59。
