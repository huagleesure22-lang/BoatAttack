# 潮岸巡游者 V2 · 新制作的人物模型

本次重新制作角色网格：自然圆润的头部与身体比例、建模眼睛/鼻/嘴、分层发束、长外套与翻领、手指、金链、靴子系带和细剑。保留蓝白金配色。

真实 Blender 模型：59916 三角形，190 个网格分件，16 根变形骨骼；全部网格有 UV 和骨骼绑定，实际动作检查确认 5342 个网格顶点随骨骼改变位置。模型源文件包含打包的布料、皮革和金属贴图，以及主光、补光和轮廓光。

Compatibility/HeroV2-Assignment-Images.zip 仅包含三张 1700×1800 PNG：正面成品、背面细节、骨骼展示。解压后按作业要求提交图片。Compatibility/HeroV2-Editable-Model.zip 是可编辑 Blender 源文件备份。

这些图片来自实际 Blender 网格渲染。新版还没有安装或验证到本机 Unity 2019 游戏角色中。
