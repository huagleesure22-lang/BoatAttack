# 潮岸遗物 · 三维数字资产作业展示版

目标环境：Unity **2019.3.0f6**、URP 7.2.1，安装在已有 IslandQuest2019 工程中。
本版聚焦数字资产的模型、UV、材质贴图、灯光与蒙皮展示。新增独立场景 `Assets/scenes/quest_portfolio_2019.unity`。

## 最简单的使用步骤

1. 关闭 Unity，全部解压安装包，双击 `Install-Assignment-Studio.cmd`。默认识别 `D:\BoatAttack-2019-From2020-28614-30466`。
2. 显示 DONE 后打开 Unity，等待编译完成。
3. 菜单 **Island2019 → 6 - Build Assignment Studio**，生成成品预制体和展示场景。
4. 菜单 **Island2019 → 7 - Export Assignment PNGs**，导出 5 张 **2200×1600 PNG**。工具会打开截图文件夹。
5. 或点击 Play：点画面下方“保存全部 5 张成品图”；它按当前 Game 窗口的双倍分辨率截图，自动隐藏操作界面。文件在工程根目录 `Screenshots` 下。
6. 检查每张图片主体完整、没有报错遮挡，再提交 PNG。通知要求只提交图片，不需要提交项目 ZIP。

Play 中：0 全景、1 主角、2 骷髅、3 武器和宝箱、4 骨骼；鼠标右键旋转、滚轮缩放；空格播放/暂停骨骼演示；F1 隐藏界面；F8 保存当前取景。

## 资产与技术内容

- **海岛剑士**：原创海军蓝服装、金属饰边、白发帽饰、披风，新增真实建模的衣缝线；2322 三角形，16 根变形骨骼。
- **骷髅守卫**：头骨、眼窝、牙齿、肋骨、脊柱、手足与武器；3115 三角形，16 根变形骨骼。
- **升级宝箱**：分块木板、拱形盖、金属包边、铆钉、锁与宝石；1508 三角形，2 根骨骼控制箱体和开盖铰链。
- **三阶长剑**：基础钢剑、青色符文剑、金色翼刃；分别 278 / 286 / 290 三角形。
- **UV 与贴图**：每个网格有明确的 UV 坐标。布料、木纹、皮革、金属、骨质、石材共 6 组 512×512 颜色与切线法线贴图（12 张），由源脚本生成；材质有独立金属度、粗糙度与青色宝石自发光。
- **蒙皮**：Unity 保存实际 `Mesh.boneWeights`、`bindposes` 和 `SkinnedMeshRenderer`。头、脊柱、肩、肘、手、髋、膝和脚形成层级；肘膝区域使用最多两根骨骼的权重，其余分件按相应骨骼绑定。运行中的动作由骨骼旋转驱动网格顶点。
- **灯光**：柔和主光、暖色补光、青色轮廓光、环境光与专用金属反射环境；单独展示台和摄影机，关闭海岛雾效。
- **骨骼图**：青色杆跟随真实骨骼的位置和方向，在模型前方偏移显示，方便观察绑定结构。它是检查辅助显示，不是骷髅怪本身的骨头网格。

生成后的可编辑资产在 `Assets/IslandQuest2019/Portfolio/Generated` 的 Meshes、Materials、Prefabs 内。贴图在 Textures 内。

## 源文件与验证范围

`Source/build_portfolio.py` 是 Blender 4.3 制作、纹理生成、骨架绑定和渲染脚本。安装包的 `SourceModels/Tideward_Portfolio.blend` 含真实网格、UV、打包贴图、Armature、顶点组和演示动画；放在工程 Assets 外，避免 Unity 调用本机 Blender 自动转换。

随附示例图片是真实 Blender Cycles 模型渲染，不是 Unity 截屏。Unity 成品截图应使用菜单 7 或 Play 内截图按钮生成。

已进行新旧输入分支 C# 编译检查（使用云端可用 Unity 2020 托管程序集）、模型 UV/权重/索引检查，以及 Blender 实际蒙皮变形检查：主角与骷髅手脚、宝箱盖确实改变网格顶点位置。云端没有运行已激活的 Unity 2019，新增展示场景仍需在本机导入并检查；不能把编译通过等同于 Unity 2019 渲染已验证。

本安装只添加 Portfolio 模块。再次安装前自动备份已有 Portfolio 目录；再次生成前自动备份已有作业展示场景。
